# React 웹 장부 앱

`apps/web`은 로컬 GraphQL API를 사용하는 React/Vite 앱입니다. 계정과 기간별 잔액, 검색·필터가 있는 거래 목록과 상세, 신규 거래 입력·복사, 시세와 동기화 상태를 제공합니다. API와 샘플 장부는 [루트 실행 안내](../../README.md#샘플로-실행하기)에 따라 먼저 시작합니다.

저장소 루트에서 실행합니다.

```sh
yarn app:web
```

<http://localhost:5173>에서 API 주소와 bearer token을 입력하고 연결합니다. 기본 API 주소는 `http://127.0.0.1:4000/graphql`입니다. endpoint는 브라우저 `localStorage`에 저장합니다. 토큰·임시 입력·확인 필요 거래의 재시도 자료는 현재 탭 메모리에만 보관하므로 새로고침하면 사라집니다. 결과가 불명확한 동안에는 새로고침하지 말고 같은 키로 재시도하거나 장부를 확인합니다. 서버 설정과 origin 허용 목록은 [API 안내](../../services/api/README.md)를 참고합니다.

계정에서 거래 목록으로 이동하고 기간·검색어·계정·태그로 범위를 좁힙니다. 기존 거래를 복사하면 모든 분개·메모·commodity·태그·코드를 유지하고 날짜를 오늘로 바꿉니다. 내용을 확인한 뒤 새 거래로 저장합니다. 입력 금액은 문자열 decimal이며 신규 거래는 단일 commodity·최소 두 분개·합계 0을 요구합니다. 기존 복수 commodity 거래를 단일 금액으로 합산하지 않습니다.

쓰기 응답이 불명확하면 입력·연결 변경과 복사를 잠그고 동일한 입력·멱등키로 재시도하여 중복 생성을 방지합니다. 연결 시 확인한 장부 식별자에 요청을 묶어 같은 endpoint가 다른 장부를 가리키면 쓰기를 거부합니다. 연결 오류와 인증 오류를 화면에서 확인할 수 있습니다. 웹 앱에는 모바일처럼 재시작 후 복구하는 영속 오프라인 대기열이 없습니다.

## 디자인 갤러리와 검증

[/gallery](http://localhost:5173/gallery)는 가상 데이터로 계정·거래·입력·시세·동기화 상태를 검토하는 갤러리입니다. 갤러리 저장 표시는 데모이며 장부를 수정하지 않습니다. `app:web`은 앱과 갤러리가 함께 있는 개발 서버를 시작하며 기존 `gallery:web`도 같은 별칭입니다.

검증 명령은 루트의 `yarn typecheck`, `yarn test`, `yarn build:web`입니다. [디자인 리뷰 체크리스트](../../docs/design-system.md)에 따라 좁은 화면, 긴 한국어 계정명, 큰 decimal·작은 소수, 키보드 포커스와 44px 조작 영역을 확인합니다. [GraphQL 타입 생성](../../docs/graphql-codegen.md)은 웹과 Expo가 공유합니다.
