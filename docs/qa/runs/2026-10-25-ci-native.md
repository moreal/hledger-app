## 실패·블로커·후속

### QA-001 · P1 · Android 인증 연결 실패

- 재현: CI 서명 파생 앱 설치 → reverse tcp4000 설정 → 설정에서 http://localhost:4000/graphql 및 유효 토큰 적용.
- 기대: 인증 확인 후 항목·거래·책 조회 가능.
- 실제: 일반 요청 오류 표시. 호스트 API는 HTTP 200.
- 다음 확인: 지원되는 신뢰 가능한 HTTPS 연결로 재검증하고 명시적 네트워크 오류 로그 확보. 이후 차단된 기능 재실행. HTTP 정책 원인은 아직 추정.

### QA-002 · P2 · 책 금액 검증 영어 내부 오류

- 재현: iOS 인증 연결 → 책 구매 폼에 ISBN·제목 등 입력 → 구매 금액을 비운 채 저장 시도.
- 기대: 저장 차단과 이해하기 쉬운 한국어 금액 입력 안내.
- 실제: 저장은 차단되나 “Decimal must…” 영어 내부 오류 노출.
- 다음 확인: 한국어 오류 매핑 수정 후 빈 값·0·음수 금액 검증 재실행.

### QA-003 · P2 · 잔액 강조 영역 글자 대비

- 재현: iOS 인증 연결 후 항목 탭의 잔액 강조 영역 확인(`balances.png`).
- 기대: 배경과 충분히 구분되는 계정명·잔액·기준일.
- 실제: 어두운 배경 위 어두운 글자가 관찰돼 읽기 어렵다.
- 다음 확인: 실제 기기/시뮬레이터에서 각 텍스트 색과 대비를 확인하고 테마 수정 후 같은 화면 재촬영.

### 남은 범위

- Android N03: 앱은 일반 요청 실패를 표시한다. 호스트 API는 200이고 reverse4000은 설정돼 있다. target SDK 36 manifest에 cleartext 허용 설정이 없어 HTTP 정책이 유력한 원인이지만, 명시적 예외 로그를 확보하지 못해 원인은 추정이다. 지원되는 신뢰 가능한 HTTPS 연결로 재검증 후 차단된 항목을 실행해야 한다.
- iOS B05: 빈 금액 검증 메시지가 영어 내부 오류로 노출된다. 한국어 입력 안내로 개선 후 재확인 필요.
- iOS 시각 관찰: `balances.png` 잔액 강조 영역에서 어두운 배경 위 글자가 어둡게 표시된다. 대비 점검 필요.
- PENDING 항목은 관찰된 하위 절차만 기록했으며 전체 항목 통과를 의미하지 않는다. B04는 iOS에서 재조회 보존·기존 표지 제거 모두 확인했고, Android는 재조회 보존만 관찰했다.
- W01은 실제 원장 쓰기를 허용하지 않는 범위여서 차단 상태다. 별도 격리 원장이 필요하다. 현재 릴리스 전체 통과를 주장할 수 없다.
