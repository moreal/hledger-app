## Environment and safety

All authenticated native interactions used `lingui-native-001` synthetic ledgers on loopback4202/4203. The web authenticated check used its empty4204 ledger. No transactions were submitted. Final audit confirmed unchanged139transactions/5books in each native fixture and0transactions/0books in the empty web fixture. [Audit](/private/tmp/hledger-qa-full-fixture/lingui-native-001/audit.json).

The existing web service had a hard-coded Node26.12.0 path which no longer existed after the machine's Node update. Its launchd entry was replaced with the stable `/opt/homebrew/bin/node` path and HTTP200 verified. Storybook was refreshed to load its new dependency/configuration. These are local environment actions, not source changes. No app-wide quit or broad process termination was used; existing developer services remain running.

Final integration also passed immutable dependency installation, catalog freshness, full typecheck, web and Storybook builds in the publishing checkout with only the selected source files. Previously untracked web entry/configuration/source dependencies are included so a fresh checkout can build the web client. The final runtime files and all tracked mobile/shared source files match the tested workspace. QA services were stopped after the unchanged-ledger audit; evidence and artifacts were retained.
