# Lingui Foundation Implementation Plan

> **For agentic workers:** Use subagent-driven-development with exclusive file ownership. User approved direct execution; no further design gate.

**Goal:** Ship shared Korean/English translation infrastructure and core screens on web and Rollipop native clients.
**Architecture:** Annotated literal descriptors feed shared PO catalogs; CLI precompiles TypeScript catalogs. App-local persistence activates a shared Lingui instance without remounting application state.
**Tech Stack:** Lingui 6.10.1, React19, Vite8, Expo58/RN0.88, Rollipop1 beta.
**Spec:** docs/superpowers/specs/2026-10-25-lingui-design.md

## Global Constraints
- Korean default; ko/en bundled offline; no implicit translation of user ledger data or numeric conversion.
- Preserve draft/outbox/auth state across language switches. Locale storage isolated from financial state.
- No full English coverage claim. Unknown-write errors must retain same-key recovery semantics.
- Main source checkout is unborn with user files; preserve it. Review/commit through existing codex/mobile-release-ci publishing checkout, never reset main.

## Review Focus
- Invalid/blocked locale storage falls back safely and never prevents ledger operations.
- Late locale hydration must not override a newer explicit user choice.
- Shared error translation must not claim failed writes definitely were not stored.
- Catalog compile must happen in clean staged native/CI builds, not depend on ignored local output.
- Native language switching must render all included messages without Intl/runtime/macros failures.
